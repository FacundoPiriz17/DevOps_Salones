# DevOps Proyecto_Salones

Aplicación de reservas de salas de estudio. Incluye perfiles de participante, funcionario y administrador, reservas, invitaciones, reseñas, sanciones y estadísticas.

El repositorio contiene el frontend React/Vite, la API Flask y el almacenamiento MySQL que utiliza la aplicación. La documentación y configuración corresponden al proyecto de DevOps.
